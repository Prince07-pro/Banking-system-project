# Banking System - Mini Project

The Banking System is a Python-based mini project that simulates basic banking operations.
It allows users to create an account, securely log in, and perform common banking activities through a menu-driven application.


# Features

 1.Create a bank account 
 2.Login using Account Number & PIN 
 3.Check account balance 
 4.Display current account balance 
 5.Deposit money 
 6.Withdraw money  
 7.Transfer money between accounts  
 8.View transaction history 
 9.Change PIN  
 10.Logout

 # concepts used

 1.Variables & Data Types   
 2.Conditional Statements   
 3.Loops  
 4.Functions  
 5.Lists & Dictionaries  
 6.String Operations  
 7.Modules
